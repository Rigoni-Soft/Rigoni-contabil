# Triage labels

Os rótulos do `triage` usam os nomes padrão (cada rótulo é igual ao papel):

| Papel | Rótulo |
|---|---|
| Categoria | `bug`, `enhancement` |
| Estado | `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` |

A esteira (`/esteira-planejar`) acrescenta a frente de cada ticket: `frente:frontend`, `frente:backend` ou `frente:ambas`.
